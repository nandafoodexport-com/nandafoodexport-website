# Nanda Food Export — Official Website

Official website repository of **PT. Nanda Food And Agriculture**, operating as **Nanda Food Export**.

This repository contains the source code for the official Nanda Food Export website, developed for presenting the company's food and agricultural products, export capabilities, company information, and customer communication channels.

## Official Website

Nanda Food Export

Website: https://www.nandafoodexport.com/

## Repository Contents

The website is primarily built using:

- HTML5
- CSS3
- JavaScript
- Responsive web design
- Structured data and technical SEO implementation

The repository also contains website assets, metadata, sitemap files, policy pages, and other resources required for production deployment.
