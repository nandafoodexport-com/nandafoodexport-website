# Security Policy

## Nanda Food Export

This security policy applies to the official website and production source code of **PT. Nanda Food And Agriculture**, operating as **Nanda Food Export**.

## Supported Version

Only the current production version of the Nanda Food Export website is actively maintained and supported.

Older, archived, experimental, or superseded versions of the website may no longer receive security updates.

## Reporting a Security Issue

If you discover a potential security vulnerability or security-related issue affecting the Nanda Food Export website, please report it privately through the official Nanda Food Export contact channels.

Please provide sufficient information to help us understand and investigate the issue, without publicly disclosing sensitive technical details.

## Responsible Disclosure

Please do not publicly disclose security vulnerabilities before they have been reviewed and, where appropriate, addressed.

Do not publish sensitive security information through public GitHub Issues, Discussions, Pull Requests, or other publicly accessible channels.

This includes, but is not limited to:

- Authentication credentials
- Passwords
- Access tokens
- API keys
- Private configuration data
- Personal or confidential information
- Detailed information that could facilitate exploitation of an unresolved vulnerability

## Security Testing

Authorization to access this public repository or website does not constitute authorization to perform intrusive, destructive, disruptive, or unauthorized security testing against Nanda Food Export systems or infrastructure.

Security research and testing must comply with applicable laws and must not interfere with the availability, integrity, or operation of the website or related systems.

## Proprietary Source Code

The source code and original materials contained in this repository remain subject to the repository's proprietary license and copyright notices.

Reporting a security issue does not grant any license or permission to copy, modify, redistribute, publish, commercially exploit, or otherwise reuse proprietary source code.

Please refer to the `LICENSE` and `NOTICE` files for additional information.

## Contact

Security-related concerns should be submitted through the official Nanda Food Export contact channels.
